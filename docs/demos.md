# Public demos

Choose a real input and follow its own overview, reference pages and local search. The hub assembles separate generated sites; it does not merge their contracts or Pagefind indexes.

- [Observatory tutorial catalog](../demos/observatory/) — an independently authored two-operation example. Start with its [observation walkthrough](../docs/reading-an-observation/) to follow `ObservationEnvelope` through a selected variant and reach `Calibration.calibration_epoch`.
- [Scalar Galaxy API reference](../demos/planets/reference/) — a pinned OpenAPI 3.1.1 API example with resource IDs, dynamic references, compositions, and a separately documented four-reference derivative.
- The separate [upstream Fumadocs Quick Start prose and visual specimen](../demos/planets/) preserves credited reference material. Its Node/npm setup describes that upstream project; it is not an Akibiyori installation guide.
- [Kubernetes API Extensions](../demos/kubernetes/) — a pinned OpenAPI 3.0.0 source with long model names, recursive references, maps and 13 operations. It is a static reader example, not a Kubernetes client.

Each destination is a local route and has its own generated search bundle. Generated examples are static and do not execute the described APIs. A page may still load its local search assets and any HTTPS images allowed by that page's documented policy. See [fixture provenance and bounds](../docs/public-fixtures/) before interpreting any example or derived value.
