# Public demos

Choose a supported generator category to explore its own real inputs, reading guides and API references. The complete showcase assembles independent generated sites; it does not merge their contracts or Pagefind indexes.

- [OpenAPI demos](openapi/) — the current category contains the four independently built examples.

Start with [Akibiyori Docs](../docs/) for project installation and authoring guidance. The composed showcase provides a shared sixteen-profile Theme picker that starts on Maple & Mist Light. The [Botanist family guide](../docs/design/botanist/) explains its Day and Night profiles, while the [Quick Start external-author walkthrough](../docs/quickstart/#build-a-botanist-demo-from-an-external-copy) builds a separate two-choice Botanist Demo from copied Observatory inputs. The examples are static and do not execute their described APIs.
