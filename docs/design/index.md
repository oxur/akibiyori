# Design guidelines

Akibiyori's reader should make the reader's task visible. A page that teaches a concept needs a different reading path from an API page that helps someone find a field or operation. Begin with the question the page answers, then give its content a clear order.

Use examples that tell the truth about their source and limits. Keep a quiet, stable reading shell so the page can carry its own emphasis. Group related details closely, give headings a meaningful hierarchy, and reserve stronger emphasis for the places that help someone act or understand.

Colour can reinforce meaning, but words, structure, and position must carry it too. Labels should still name a method or state; a colour alone is not a reliable instruction. These guidelines describe the reader that exists today. They do not promise a contrast result or introduce new theme values.
