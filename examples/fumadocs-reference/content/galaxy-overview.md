# Scalar Galaxy

Scalar Galaxy is an illustrative planetary catalog contract. Its generated reference lets you follow a single planet lookup, a paginated collection response, and the schemas that connect them.

Start with the [reading guide](reading-the-galaxy/) to trace those source relationships, or browse the [Scalar Galaxy API reference](../reference/). The [upstream Fumadocs Quick Start](../) and [What is Fumadocs](what-is-fumadocs/) remain separate credited specimen pages; they document Fumadocs rather than this API.

The source is the pinned Fumadocs Scalar example. The generated reader uses a separately documented derivative with four response-reference corrections; it presents schema facts and bounded examples without contacting a service.
