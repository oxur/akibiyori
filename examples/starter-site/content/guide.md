# Reading a reading

The [readReading operation](../../reference/readReading/) accepts a numeric `readingId` in the path. Its example response contains a `Reading` with an identifier and a temperature in degrees Celsius.

The example contract documents a request and response shape only. It does not contact a station or execute an API request.
