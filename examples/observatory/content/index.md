# Observatory Catalog

The Observatory Catalog is a small teaching contract for following an observation from its response envelope through measurement alternatives to an instrument calibration timestamp. Begin with the [observation walkthrough](docs/reading-an-observation/) for that field path, then use the [Catalog API reference](reference/) to browse the generated operation and model pages.
